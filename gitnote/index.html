Your Data, Your Rules

不存别人服务器，数据只属于你

没有私有云、没有订阅墙。Git记只是你与 Git 仓库之间的一座桥。

连接你的仓库

通过 SSH / HTTPS 连接 GitHub、GitLab、Gitee 或任何自建 Git 服务，笔记直接读写你自己的仓库。

完全掌控

第三方便捷、自建更私密，随你选择。所有历史版本、分支、备份都掌握在你手里。

永不锁死

笔记是纯 Markdown、图片是普通文件。随时导出、随时迁移、随时离开，没有任何枷锁。

Features

为「记录」而生的完整能力

从连接仓库到编辑、检索、同步、回溯，每一步都顺手。

第三方 & 自建仓库

支持 GitHub / GitLab / Gitee 等第三方平台，也支持你自己搭建的 Git 仓库。

SSH / HTTPS 连接

用加密通道连接你的仓库，数据只属于你自己，不需要存到任何别人的服务器。

自动同步

编辑完成即自动 commit & push，多设备间的数据始终一致，无需手动操心。

冲突由你处理

出现冲突文件时清晰展示差异，合并或保留由你决定，绝不悄悄覆盖。

FTS 全文检索

内置全文检索，匹配更精准，笔记再多也能马上找到你要的那一条。

图片随笔记入库

粘贴的图片会跟着笔记一起存入 Git 仓库，引用永不断链，所见即所有。

DIFF 视图

每一次修改都以 diff 形式一目了然，改动、增删、历史版本清晰可见。

完善 Markdown 编辑器

图片、图标、公式、表格一样不少，所见即所得的编辑体验，写起来停不下来。

跨平台一起用

iOS / macOS / Android / 鸿蒙 全覆盖，走到哪儿记到哪儿，数据无缝衔接。

纯原生实现，性能优先

不使用 WebView 与跨平台运行时，iOS / macOS / Android / 鸿蒙 各自以平台原生技术构建。启动快、占用低，滚动与编辑始终顺滑流畅。
